# Station 67 — веббілд

Кооперативна фізична комедія від першої особи: пожежники, рукави, сокири, батути й вода, яка гасить вогонь
і збиває з ніг. Тут лежить лише зібрана Unity WebGL-гра.

**Грати:** https://vorotnikovandrey.github.io/station67-web/

- Найкраще працює в Chrome або Edge на комп'ютері. Мобільні браузери не підтримуються.
- Перше завантаження займає час, далі браузер бере файли з кешу.
- Одиночна гра запускається з лобі одразу. Для гри вдвох-учотирьох один гравець створює кімнату, решта приєднуються.
- Браузер пригальмовує вкладку у фоні, тож хост зі згорнутою вкладкою гальмує гру всім.
